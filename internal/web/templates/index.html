Prometheus → 飞书 告警网关

一个高性能的 Webhook 服务，接收 Prometheus Alertmanager 告警，格式化成交互式卡片推送至飞书，并提供带登录鉴权的管理后台。

前往管理后台 → 健康检查
🔔

实时推送

将 Alertmanager 告警实时转为美观的飞书卡片，支持 firing / resolved 双状态。

🛠

在线配置

后台可视化编辑卡片模板与 Webhook 地址，支持环境变量覆盖，便于容器部署。

📜

推送日志

完整记录历史告警与飞书推送结果（成功 / 失败 / 异常），便于排查问题。
